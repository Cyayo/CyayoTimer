# ⏰ CyayoTimer - Automated Event Manager

"Jadwalkan event dan hadiah secara otomatis. Kelola boss event dan reward claim dengan sistem timer yang presisi."

```text
=========================================
             QUICK TUTORIAL
=========================================
```

### 1. Cara Klaim Hadiah
- Gunakan command `/claim` atau `/hadiah` untuk membuka menu pengambilan hadiah berkala.
- Hadiah akan tersedia setiap interval waktu yang telah ditentukan oleh admin.

### 2. Boss Event
- Plugin ini secara otomatis akan memunculkan Boss di lokasi tertentu berdasarkan jadwal yang diatur di `bosses.yml`.
- Pemain yang berkontribusi paling banyak akan mendapatkan reward spesial.

```text
=========================================
     CYAYOTIMER - COMMANDS & PERMS
=========================================

USER COMMANDS:
/claim                       > Klaim hadiah waktumu.

ADMIN COMMANDS:
/cyayotimer reload           > Reload konfigurasi plugin.
/cyayotimer spawn <boss>     > Spawn boss secara manual.

PERMISSIONS:
cyayotimer.use               > Izin dasar klaim hadiah.
cyayotimer.admin             > Master permission (Akses Semua).
```

### 🚀 Advanced Features
- 🐲 **Boss System** - Integrasi dengan MythicMobs untuk event boss yang epic.
- 🎁 **Scheduled Rewards** - Pemberian hadiah otomatis (Item, MMOItems, atau Command) berdasarkan waktu bermain.
- 📊 **Hologram Display** - Tampilan sisa waktu boss atau event menggunakan FancyHolograms.
- 🔔 **Global Announcements** - Notifikasi otomatis ke seluruh server saat event akan dimulai.
